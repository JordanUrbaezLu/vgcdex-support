# Champions VGC Dex — support site

Support and privacy-policy pages for **Champions VGC Dex**, an unofficial doubles battle companion for iPhone, served by GitHub Pages:

- Support: https://jordanurbaezlu.github.io/vgcdex-support/
- Privacy policy: https://jordanurbaezlu.github.io/vgcdex-support/privacy.html

Bug reports, data corrections, feature requests and removal requests: email **paul3paulpaul@gmail.com** (no account needed; private) or [open an issue](https://github.com/JordanUrbaezLu/vgcdex-support/issues/new).

The app's source lives in the private repo `JordanUrbaezLu/champions-vgc-dex` (release steps and history in its `RELEASE.md`). When v1.1 adds anonymous usage analytics, `privacy.html` must be updated **before** that build ships — see that repo's `docs/analytics.md`.

Unofficial fan-made app — not affiliated with Nintendo, Creatures Inc., GAME FREAK inc., or The Pokémon Company.
